# Reference library

Design intelligence, not a bookmarks folder. Each reference is a short note on **why** something
works, so the principle can be reused without copying the work. Never put another creator's frames
into a video; keep captured frames here for study only.

- Add a note: copy `TEMPLATE.md` to `<yyyy-mm>-<slug>.md`.
- `backlog.md`: things a video needed that the studio could not express yet (input for `extend-studio`).
